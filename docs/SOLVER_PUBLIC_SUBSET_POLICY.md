# Публичные подмножества для локального теневого режима

24 октября 2026. Политика `anchored_public_subset_v1`, только диагностика.
Флаг остаётся выключенным в обычном запуске, советы игроку не заменяются.

## Как включить флаг

Из корня репозитория, после остановки обычного локального backend:

```bash
PYTHONPATH=backend backend/.venv/bin/python -m research.local_shadow_server
```

Команда проверяет конфигурацию и явно собранную native-библиотеку, затем
выставляет только в своём процессе:

```text
POKER_LOCAL_TRAINER_SHADOW=1
POKER_LOCAL_TRAINER_SHADOW_PLAN=<абсолютный путь к backend/research/config/local-shadow-policy.json>
```

Запускается один worker Uvicorn на `127.0.0.1:8000`; порт можно изменить через
`--port`, конфигурацию — через `--plan`. При отсутствии native-библиотеки нужно
отдельно выполнить `research/build_native.py`. Автосборки, изменения `.env`,
GitHub secrets, Render или Vercel нет. Не нужно запускать второй backend поверх
уже занятого порта. Остановка — Ctrl+C; следующий обычный запуск снова будет
без флага, если переменные отдельно не были заданы пользователем в окружении.

Готовый [конфиг](../backend/research/config/local-shadow-policy.json) версии 2
явно требует `mode: diagnostics_only`. Он не разрешает подмену подсказок.
По умолчанию выбираются по 3 руки на живое место, seed 20261024, бюджет до 4096
исходных сочетаний; 100 итераций, 10 секунд и 128 МиБ на расчёт. На 6 местах
это 729 исходных сочетаний. Прежние точные планы версии 1 тоже поддерживаются.

## Как выбираются руки

Источник — полный публичный диапазон каждого живого места из schema-v1 снимка.
Список сортируется канонически и перемешивается детерминированно по публичному
ключу, id места и заданному seed. Выбирается равномерное подмножество без
повторений; исходные веса публичной модели сохраняются.

Для текущего актора его известная рука явно ставится первой, остальные берутся
из того же порядка. Это **якорь собственной руки**, а не чтение скрытой руки
соперника. Выбор диапазонов соперников не зависит от этой руки. Сфолдившие
места не получают диапазонов. Конфликты карт исключаются последующим полным
перебором совместимых сочетаний, как в прежнем прототипе.

Seed не зависит от ширины: при расширении набора старые выбранные руки
сохраняются. Ширина не уменьшается автоматически при превышении бюджета.
Если нет совместимых раскладок для собственной руки или нарушен лимит
дерева/сочетаний, контракт явно отказывает. Повторный подбор «удачного» seed
не выполняется.

Это конечная перенормированная выборка, а не несмещённая оценка полного
диапазона. Якорь меняет собственный диапазон, а значит и модель ответов
соперников. Она может дать другое решение, даже когда CFR хорошо решил
получившуюся малую игру. `range_stability_verified` явно установлен в `false`.

Размеры дерева в конфигурации выражены в больших блайндах: открытие до 2/4 BB,
рейзы до 8/12 BB. Это итоговые суммы улицы, не добавленные фишки; незаконные
размеры исключаются деревом. По настройке включается точный размер текущего
совета тренера. Размеры ограничиваются доступными начальными стеками ривера,
дедуплицируются; лимит четырёх размеров/трёх будущих рейзов не повышается.
Текущее дерево по-прежнему ограниченная абстракция, особенно при больших ставках.

## Проверка чувствительности

[Отчёт](research/public-subset-sensitivity-2026-10-24.json): 10 фиксированных
публичных ситуаций на 2–6 местах и двух бордах. Во всех случаях одна и та же
пробная рука актора включена в малый и более широкий вложенный набор.
Ширина малого — 3; широкого — 16/8/6/4/4 для 2/3/4/5/6 мест.
В обоих расчётах одинаковое дерево: ставка 10, рейз до 40, один будущий рейз.
Это отдельный контролируемый тест диапазонов, а не всего BB-дерева конфигурации.

Из 20 расчётов **19 прошли** ограниченный порог 0,5% банка. Один широкий
шестиместный случай отклонён по прежнему лимиту миллиона пар «узел/раскладка»;
политика не уменьшила ширину за пользователя. Из 9 сопоставимых пар только
6 сохранили наиболее вероятное действие, 5 уложились в диагностическое
расстояние TV ≤ 0,15. Этот TV-порог — индикатор чувствительности, не сертификат
качества и не условие допуска к замене совета.

| Ситуация | Малый / широкий наиболее вероятный ход | TV | Итог |
|---|---|---:|---|
| dry_2 | FOLD / FOLD | 0.3364 | совпало |
| dry_3 | RAISE 40 / RAISE 40 | 0.0002 | совпало |
| dry_4 | FOLD / CALL | 0.6030 | изменилось |
| dry_5 | FOLD / FOLD | 0.0000 | совпало |
| dry_6 | FOLD / FOLD | 0.0000 | совпало |
| flush_2 | FOLD / CALL | 0.9982 | изменилось |
| flush_3 | FOLD / FOLD | 0.0000 | совпало |
| flush_4 | FOLD / CALL | 0.9555 | изменилось |
| flush_5 | FOLD / FOLD | 0.0000 | совпало |
| flush_6 | — | — | широкий расчёт отклонён |

TV — половина суммы абсолютных различий вероятностей действий для одной
и той же собственной руки. Нулевое значение означает одинаковую корневую
стратегию, единица — непересекающиеся стратегии. Широкий набор здесь тоже
далеко не полный и не считается правильным эталоном. Полученные расхождения
показывают, что малые диапазоны ещё **не прошли проверку устойчивости**.
Положительная метрика качества внутри каждой игры не снимает эту проблему.

## Локальный сквозной прогон

[Отчёт флага с политикой](research/trainer-policy-shadow-2026-10-24.json)
проверяет настоящий маршрут тренера, конфигурацию версии 2, native-очередь,
сравнение после обычного ответа и чистую остановку. В диагностике записаны
название политики и хеш выбранных диапазонов; сырые карты в журнал не пишутся.
`diagnostics_only: true`, `range_stability_verified: false` и
`live_advice_allowed: false` сохраняются явно.

```bash
PYTHONPATH=backend backend/.venv/bin/python -m research.benchmark_subset_policy
PYTHONPATH=backend backend/.venv/bin/python -m research.benchmark_trainer_shadow --policy-plan backend/research/config/local-shadow-policy.json
PYTHONPATH=backend backend/.venv/bin/python -m unittest discover -s backend/tests -p test_public_subset_policy.py
```

## Что дальше

Работать над устойчивостью диапазонов: больше разнообразных собственных рук,
повторные seed, сравнение ширин и затем сжатие/взвешивание вместо нескольких
случайных представителей. До отдельной проверки этого приближения флаг
предназначен для локальных наблюдений, а не для переключения действующего тренера.
