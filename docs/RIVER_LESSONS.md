# Учебный разбор ривера — локальная первая версия

25 октября 2026. Из «Практики» открывается `/practice/river`: пять фиксированных
примеров с 1–5 оппонентами, видимыми диапазонами и отдельным расчётом модели.
Это первый пользовательский экран собственного ограниченного решателя.
Обычные советы тренера и комнаты с друзьями не переключаются на солвер.
Ссылка в «Практике» появляется только на сервере с включённым вычислителем.

## Что можно сделать

1. Выбрать число оппонентов. У каждого примера свои борд, известная рука ученика
   и диапазоны; смена числа выбирает другой пример, не добавляет игроков в ту же руку.
2. Посмотреть банк, стеки, предыдущие вклады, блайнды, возможные ставки и диапазоны
   с относительными весами. У каждого места ровно две возможные комбинации.
3. Запустить расчёт, отменить его или сменить пример во время вычисления.
4. При прохождении проверки увидеть частоты CHECK / BET 10 / BET 20 и измеренную
   выгоду лучшего одностороннего отклонения в процентах банка этой модели.

Рука ученика известна, остальные комбинации — допущения модели, не раскрытые
карты реальных соперников. Политика рассчитывается для обеих собственных рук,
показанные частоты условны на выбранную руку ученика. Качество проверяется
по всему профилю исходной малой игры; это не отдельная гарантия каждой редкой руке.
Небольшие частоты округляются до одного десятичного знака процента.

Это не импорт игровой раздачи. Примеры не изменяют текущую руку, сохранённые
решения или прогресс обычных упражнений. Отдельного EV для каждого действия
и объяснений через LLM в этой версии нет. Интерфейс доступен на RU / UA / EN.

## Расчёт и ограничения

Используются существующие `analysis_contract.analyze`, `ShadowExecutor`,
`river_snapshot` и native CFR+. Исследовательские модули не переписаны ради UI.
Во время запроса выполняются постановка в очередь и отдельный опрос результата;
HTTP-запрос не ждёт полного расчёта, игровые действия не блокируются.

Параметры фиксированы на сервере:

- 300 итераций, 10 секунд и 128 MiB наблюдаемой RSS на отдельный расчёт.
- Один worker и до двух ожидающих расчётов; до 64 сохранённых подписок/профилей.
- 2–6 мест, 2 руки на место, не больше 64 исходных совместных комбинаций.
- Не больше 4000 публичных узлов, ставки 10/20, будущие рейзы выключены.
- Порог качества ≤0,5% банка; точный лучший ответ измеряется внутри ограниченной
  игры после обучения. Порог и размеры клиент изменить не может.

Все пять текущих примеров прошли проверку в локальном HTTP-прогоне; наблюдаемые
ошибки 0,0173–0,0906% банка. Эти учебные входы не являются независимым аудитом
решателя или подтверждением качества на всех риверах и полных диапазонах.
Для нескольких игроков итерации CFR+ не дают общей гарантии сходимости;
допуск определяется измерением, а не числом итераций.

Веса сохранены из явно выбранных учебных подмножеств публичной эвристической
модели диапазонов. Совместимость карт проверяется целыми раздачами. Рейк,
card bunching сброшенных рук, другие улицы и альтернативные размеры вне дерева
не моделируются. Входы зафиксированы в
`backend/research/fixtures/river-lessons-v1.json`, версия каталога — SHA-256 файла.
Обновлённая версия каталога отклоняет старый запрос до запуска расчёта.

При ошибке, превышении бюджета или непрохождении качества частоты не выдаются.
Интерфейс показывает понятную причину. Отмена известной задачи передаётся
исполнителю; дочерний процесс останавливается, если нет других подписчиков.
Смена примера/закрытие страницы прекращает клиентское ожидание и отменяет
полученный ticket. Если ответ на постановку потерян до получения ticket,
ограниченный расчёт может закончиться без отображения; следующий запрос того
же профиля вытесняет предыдущую подписку. Старый результат не показывается
для новой версии/примера. На клиенте есть общий лимит ожидания 45 секунд.

## API и изоляция

- `GET /api/river-lessons` — каталог и доступность; без запуска процесса.
- `POST /api/river-lessons/jobs` — только `{lesson_id, version}`; дополнительный
  снимок, диапазоны или настройки запрещены схемой.
- `GET /api/river-lessons/jobs/{ticket_id}` — состояние своей подписки.
- `DELETE /api/river-lessons/jobs/{ticket_id}` — отмена своей подписки.

Операции с задачами используют существующий анонимный профиль практики и Bearer
токен. Чужие poll/cancel возвращают 404, запрос без профиля — 401. Ответы задач
имеют `private, no-store` и `Vary: Authorization`. Каталог публичный и `no-store`;
в нём только учебные допущения. Один профиль имеет одну текущую подписку.
Это не регистрация пользователя и не учёт трёх бесплатных LLM-разборов.

## Локальный запуск

По умолчанию режим выключен. Без флага исследовательские/native-модули вообще
не импортируются при старте обычного приложения. На отключённом сервере экран
показывает, что вычислитель не подключён. Текущий production Dockerfile не
копирует research/native: размещение на Render — отдельная работа.

Из корня репозитория, при уже установленном окружении и явно собранном ядре:

```bash
PYTHONPATH=backend backend/.venv/bin/python -m research.build_native
POKER_LOCAL_RIVER_LESSONS=1 PYTHONPATH=backend backend/.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Флаг читается при старте API. Фронтенд использует существующий
`NEXT_PUBLIC_API_BASE_URL`. Ядро не компилируется автоматически по HTTP-запросу.

Во время разработки поднят отдельный запуск, сохраняющий существующий стол:

```bash
env -u POKER_DATABASE_URL -u RENDER POKER_LOCAL_RIVER_LESSONS=1 POKER_DB_PATH=/tmp/poker-river-lessons-preview.sqlite3 POKER_ROOM_ORIGINS=http://127.0.0.1:3001,http://localhost:3001 PYTHONPATH=backend backend/.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8011 --no-access-log
```

И из `frontend/`:

```bash
POKER_NEXT_DIST_DIR=.next-river-preview NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:8011 npm run dev -- --hostname 127.0.0.1 --port 3001
```

Открыть `http://127.0.0.1:3001/practice/river`. Папки `.next-river-*` — отдельные
временные сборки; обычные настройки сборки сохраняются без переменной.

## Проверки

- 427 backend-тестов успешно, 3 пропущены, включая 6 новых проверок каталога,
  профилей, строгого запроса, вместимости и отсутствия research-импорта по умолчанию.
- 45 frontend-тестов успешно, включая проверки настоящего React-компонента: двойной запуск, смена примера,
  поздние submit/poll, скрытие кандидата при отказе качества и выключенный режим.
- Сквозной [HTTP-отчёт](research/river-lessons-http-2026-10-25.json): все 5 примеров
  ready через настоящий native subprocess; проверены авторизация, чужие запросы,
  отмена, заголовки кэша и сохранность обычной руки. Токены в отчёт не записываются.
- Production-сборка включает `/practice/river`. TypeScript и линтер изменённых
  компонентов/сервиса проходят. ESLint переведён с несовместимого FlatCompat
  на нативные flat-конфиги установленного Next.js.
- В браузере проверены реальные расчёты, RU/UA/EN, раскладки 390 и 1440 px.

Следующее расширение: значения действий (с явно указанным продолжением), затем
перенос выбранных завершённых учебных раздач с явными допущениями диапазонов.
Общий солвер широких диапазонов остаётся отдельным исследованием.

Повторить HTTP-проверку на отдельном локальном тестовом API:

