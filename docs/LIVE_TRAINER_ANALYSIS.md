# Анализ во время тренировочной раздачи

Актуально на 25 октября 2026. Уточнённый основной сценарий: подсказка помогает
выбрать действие, пока игрок принимает решение в режиме тренера. Архив и
отдельная «Практика» дополняют этот сценарий, но не заменяют его.

## Что уже работает

При ходе героя тренер отдельно загружает обычную подсказку через
`/api/hand/analyze`. Игровые действия не должны ждать её расчёта.
`LatestAnalysis` отменяет прежний запрос и игнорирует поздний ответ после
смены состояния. Этот путь использует `DecisionEngine`: эквити, эвристические
рекомендации и размеры, EV колла без последующей торговли.

Новый решатель ривера пока обслуживает примеры и завершённые решения.
Решатель тёрна существует отдельно как offline-модуль. Ни один из этих
расчётов ещё не заменяет совет в текущей тренировочной раздаче.
Локальный shadow-режим собирает исследовательскую диагностику, а не показывает
готовый результат игроку.

## Ближайшая продуктовая поставка

**Подключить ограниченный расчёт ривера прямо к панели «Тренер».**
Этот шаг имеет приоритет перед новым экраном практики тёрна.

Когда ход переходит к герою:

1. Обычная подсказка поступает существующим быстрым путём; кнопки доступны.
2. В фоне запускается дополнительный solver-расчёт поддерживаемой позиции.
   В панели видны состояние расчёта и источник уже доступной подсказки.
3. После успешного расчёта появляются частоты и EV доступных действий,
   конкретные размеры ставок/рейзов, диапазоны и ограничения выбранной модели.
4. После действия героя, перехода улицы или начала новой руки прежний
   результат сразу снимается. Расчёт для устаревшей позиции не публикуется.
5. Неподдерживаемая позиция, нехватка покрытия или превышение бюджета оставляют
   обычную подсказку доступной. Результат малой модели не выдаётся за решение
   всей исходной игры и не получает общее обозначение «оптимальный ход».

Результаты должны быть видны в существующей панели тренера на мобильном
и десктопном экранах. Отдельный переход в архив для получения текущего совета
не требуется. Нельзя прятать игровой ход за ожиданием решателя.

## Отдельный путь текущей позиции

Существующий запрет анализа незавершённых решений через history API остаётся:
он относится к маршруту истории, а не определяет назначение тренера.
Для текущего хода нужен новый адаптер и контракт, а не простая смена
`live_advice_allowed` у прежнего offline-результата.

- Сервер берёт состояние собственного тренировочного стола авторизованного
  профиля; проверяет, что ход героя открыт. Входом модели служат его карты,
  публичный борд, банк, стеки и наблюдённые действия.
- Скрытые карты ботов, содержимое колоды, будущий борд и seed раздачи
  не входят в запрос решателя. Диапазоны строятся по доступной игроку информации.
- Задача привязана к профилю, руке, версии полного состояния решения
  и версии модели. Она исполняется изолированно, без удержания блокировки стола.
- Перед публикацией сервер повторно сверяет версию позиции; клиент также
  проверяет её. Одного совпадения улицы или hand_id недостаточно.
- Повторный запрос той же позиции использует собственную задачу/результат;
  новая позиция отменяет прежнее ожидание. Очередь и кэш имеют явные пределы.
- Модельные EV, размеры и список действий сопоставляются с текущими легальными
  действиями. Измерение качества внутри поддиапазона не доказывает достаточное
  покрытие исходной позиции; границы применимости показываются отдельно.

Регистрация аккаунта не добавляется как условие обычной вычислительной
подсказки этим планом. Существующий профиль тренировочной сессии используется
для изоляции стола. Регистрация, три бесплатных разбора и подписка относятся
к будущему объяснению через LLM API согласно согласованной идее.

## Последующие улицы

После первой работающей интеграции ривера — подключить тёрн тем же способом.
До этого эталон тёрна должен поддерживать наблюдённые действия и рейзы, чтобы
анализировать реальный ход героя, а не только начало синтетической улицы.
Затем расширение на флоп и позиционные диапазоны префлопа.

На каждой улице интерфейс указывает реально доступный метод. Наличие эквити
или эвристической ставки не означает готовность solver EV с будущей торговлей.
Голословная замена всех подсказок числом из малой модели не входит в поставку.

## Критерий завершения ближайшего шага

Локальная тренировка на ривере показывает расчёт текущего хода до выбора
действия. Проверены позиции с 1–5 оппонентами: для поддержанных моделей —
привязанные EV и частоты, для остальных — явная причина отсутствия результата.
Проверены смена позиции во время расчёта, две независимые сессии, таймаут,
отмена, отсутствие доступа к скрытым картам и сохранение отзывчивости игры.
После этих проверок — отдельная проверка времени, памяти и поведения на staging.
