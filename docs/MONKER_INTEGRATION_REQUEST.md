# MonkerSolver integration inquiry — draft, not sent

Recipient: support@monkerware.com
Subject: Commercial headless/API integration for 2–6 player Hold'em hand reviews

Hello,

We are developing a private poker training application with virtual chips and
post-hand coaching. We are evaluating a solver for No-Limit Texas Hold'em with
2–6 players, including 4–6 active players on flop, turn and river.

Before considering a purchase, could you confirm:

1. Is there a supported API, CLI, SDK or headless batch mode? Which operating
   systems are supported for unattended server jobs, particularly Linux?
2. Can it solve 4–6-way postflop trees with individual weighted ranges, unequal
   stacks, side pots, prior street actions and custom bet/raise sizes?
3. Can we export per-combination action frequencies, action EVs and convergence
   diagnostics in a documented machine-readable format?
4. What license permits a server application to offer saved post-hand analyses
   to multiple paying subscribers? May we cache results, use job queues, and
   generate explanations of the results? Are separate SDK/server rights needed?
5. Is a technical evaluation build available with these interfaces? Can you
   provide representative 3-, 4-, 5- and 6-way postflop time/RAM requirements?
6. Are there restrictions on concurrency, cloud hosting, containers, result
   redistribution, or subscriptions built around generated analyses?

Our prototype currently exports public decisions, complete per-player ranges,
individual stacks/contributions and action history. We do not want to assume
that a normal personal desktop license grants these integration rights.

Thank you.
