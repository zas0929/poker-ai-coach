# Независимая выборочная проверка фиксированной стратегии

Обучение и проверка теперь используют отдельные выборки. На десяти известных
малых играх выполнены **180 оценок двух типов фиксированных политик**. Во всех
оценках консервативные интервалы содержали точные значения, но оказались слишком
широкими для допуска по порогу 0,5% банка. Игровой тренер и флаги прежние.

Это продолжение [выборки раздач](SOLVER_DEAL_SAMPLING.md), где проверка на
обучающих данных дала 49 ложных успехов относительно исходной игры среди 66
сравнимых политик. Здесь новые данные проверки, но сами десять игр уже известны:
это не новый независимый игровой корпус.

## Отделение обучения от проверки

Для каждой игры до просмотра проверочных выборок обучаются две политики:

- `exact_trained`: 100 итераций CFR по точному совместному распределению.
- `sample_trained`: 100 итераций по фиксированной выборке из 512 раздач, seed 11.

Для второй политики требуется полное покрытие исходных информационных строк.
Если его нет, обучение не дополняется выдуманными решениями, случай отклоняется.
В данном прогоне все десять обучающих выборок имели полное покрытие. Эти же
выборочные политики использовались в предыдущем исследовательском этапе;
метод не подбирался по новым данным проверки.

Размеры проверки: 128/512/2048 принятых раздач. Для каждого размера три заранее
заданных seed: `1009 + 10*N`, `2017 + 10*N`, `3001 + 10*N`. Они не совпадают с
seed обучения. На одной проверочной выборке оцениваются обе фиксированные
политики: результаты пары зависимы, их нельзя считать независимыми испытаниями.
Различие seed само по себе не доказывает математическую независимость; вывод
о границах ниже предполагает модель независимых одинаково распределённых
принятых раздач. Используется детерминированный локальный PRNG.

В отличие от обучения, проверочная выборка может не содержать некоторые руки:
политика для них уже зафиксирована до проверки. Для расчёта используется
ограничение исходной политики на встретившиеся строки; новые решения не
создаются. Для границы неопределённости берутся **все исходные строки**, включая
не встретившиеся в проверке. На 128 раздачах неполное проверочное покрытие было
в 16 из 60 оценок, на двух больших размерах — ни в одной.

## Почему одного независимого расчёта недостаточно

Выплата фиксированной политики — среднее по случайным раздачам. Но лучший
ответ выбирается после просмотра данных: максимум по выборочным выплатам
разных ответов в общем случае завышает лучший ответ относительно истинного
распределения. Отделение обучения стратегии от проверки устраняет повторное
использование обучающих данных, однако не устраняет этот эффект максимизации.
По отдельной конкретной выборке ошибка может иметь любой знак.

Добавлена явная консервативная граница для этой небольшой конечной модели.
Для игрока i:

- `[L_i, U_i]` — минимум и максимум его терминальной выплаты в полной игре;
  `R_i = U_i - L_i`.
- `K_i` — произведение числа действий во всех его исходных информационных
  строках: число чистых стратегий ответа. Используется `log(K_i)` без их перебора.
- `N` — число независимых принятых раздач, `delta` — бюджет ошибки одной оценки.

Для выплаты политики радиус Хёффдинга:

```text
r_value_i = R_i * sqrt(log(4*n/delta) / (2*N))
```

Для лучшего ответа радиус с объединением событий по всем чистым ответам:

```text
r_response_i = R_i * sqrt((log(K_i) + log(4*n/delta)) / (2*N))
```

Двусторонние интервалы обрезаются по `[L_i, U_i]`. Нижняя граница выгоды —
`max(0, response_lower - value_upper)`, верхняя —
`max(0, response_upper - value_lower)`. Условие допуска по верхней границе
применяется к максимальной выгоде среди игроков в процентах банка решения.
Случайное отклонение ответа охватывается максимумом по конечному множеству
чистых ответов; дерево имеет совершенную память, как и точный оценщик.

Доказательная идея: для каждой фиксированной политики ответа случайная
выплата лежит в том же терминальном диапазоне. Двусторонняя граница для одной
выплаты даёт множитель 2, объединение по K ответам — ещё K. Бюджеты распределены
между профилем и ответом каждого игрока. Одновременное покрытие всех фиксированных
ответов сохраняется при взятии максимума. Поэтому нельзя использовать радиус
одной заранее выбранной политики как радиус найденного на выборке максимума.

На каждую из 180 запланированных оценок выделено `delta = 0,05 / 180`.
По объединению событий семейная вероятность выхода за интервалы не больше
0,05 в идеальной IID-модели. Независимость между отдельными оценками для этого
объединения не нужна. Граница предполагает фиксированные до проверки политики,
корректные терминальные пределы, распределение и идеальную арифметику; она не
покрывает ошибки реализации/модели или последующий адаптивный подбор по отчёту.
Повторные запуски и выбор лучшего результата без нового бюджета ею не покрыты.
Все результаты помечены `diagnostics_only`, `live_advice_allowed=false`.

## Измерения

[Полный отчёт](research/independent-evaluation-2026-10-24.json) содержит параметры,
входы, исходники с SHA-256, точные и выборочные выплаты, лучшие ответы,
интервалы, ошибки и покрытие. Все десять случаев завершились в исходных лимитах
45 секунд и 128 MiB наблюдаемой RSS на случай. Ширины диапазонов, борды,
единственное открытие 40 и отсутствие последующих рейзов прежние.

Из **20 разных политик** точный порог прошли все десять `exact_trained` и шесть
из десяти `sample_trained`. В таблице каждая политика проверяется тремя seed,
поэтому точных успехов 48 из 60 на каждом размере, а не 48 разных стратегий.

| Раздач проверки | Оценок | Прошли точный порог | Прошли порог по точечной оценке | Ложных допусков | Ложных отказов | Допусков по верхней границе |
|---|---:|---:|---:|---:|---:|---:|
| 128 | 60 | 48 | 5 | 0 | 43 | 0 |
| 512 | 60 | 48 | 20 | 0 | 28 | 0 |
| 2048 | 60 | 48 | 39 | 0 | 9 | 0 |

Ложный допуск: точечная проверочная оценка ≤0,5%, точная метрика >0,5%.
Ложный отказ: обратная ситуация. Отсутствие ложных допусков на этом наборе
не является гарантией для следующих выборок или других игр.

Все интервалы покрыли точные значения в 180/180 оценок. Это наблюдение, а не
измеренная вероятность покрытия 100%: оценки связаны, игр мало, а интервалы
заведомо широкие. Верхняя граница максимальной выгоды при 2048 раздачах
составила **20,49–32,34% банка**, намного выше порога 0,5%. Нулевое число допусков
по этой границе — подтверждение её ограниченной практической полезности здесь,
а не доказательство плохого качества всех обученных стратегий.

Средняя ошибка лучшего ответа по игрокам и оценкам была положительной для
обоих типов политик на всех размерах, но отдельные ошибки имеют оба знака.
Три seed на игру недостаточны для надёжной оценки смещения и хвостов ошибки.
Увеличение размера уменьшило число ложных отказов в данном опыте; общий закон
скорости сходимости для реальных диапазонов этим не установлен.

## Ограничения и следующий этап

Всё ещё строится полная малая игра: из неё получены терминальные пределы,
исходные информационные строки и точный эталон. Группировки нет, MCCFR не
реализован, широкие диапазоны и полный NLHE не решены. Фронтенд, живые подсказки
и конфигурация хостинга не менялись.

Следующий этап — отдельно построить кандидат лучшего ответа, затем проверить
**фиксированное отклонение** на третьей выборке. Парная оценка разницы выплат
на одинаковых раздачах может уменьшить шум и помочь надёжнее находить ошибки.
Она даёт нижнюю диагностику доступного отклонения, а не верхнюю гарантию для
оптимального ответа: отсутствие найденной ошибки не означает прохождение
порога. Практический верхний допуск остаётся отдельной нерешённой задачей.

Пять новых тестов проверяют пропущенные проверочные руки без дополнения
политики, отказ частичных входов, влияние числа ответов/раздач, точный
биномиальный контроль вероятности выхода за границы и терминальные пределы.
