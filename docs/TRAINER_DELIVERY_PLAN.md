# Тренер: текущий этап и ближайшая поставка

Актуально на 25 октября 2026. Этот план задаёт текущие приоритеты.
[Общий roadmap](ROADMAP.md) также хранит историю прежних этапов и экспериментов.

## Первая локальная поставка выполнена — 25 октября 2026

Из «Практики» доступен `/practice/river`: пять примеров с 1–5 оппонентами,
заданные диапазоны, параметры дерева, асинхронный запуск/отмена, проверка
качества и частоты действий. Все пять рассчитались через настоящий HTTP API
и native-процесс. Ограниченный разбор теперь доступен на staging; основной
совет игрового тренера не заменён.
[Возможности, запуск и проверки](RIVER_LESSONS.md).

EV доступных действий добавлен локально: ожидаемый результат от текущего
решения, частоты, разница с лучшим первым действием и явное фиксированное
продолжение. Добавлен [разбор завершённых решений ривера](RIVER_HISTORY.md):
свой сохранённый ход, явные подмножества диапазонов, покрытие и сравнение EV.
Проверены настоящие завершённые руки на 2–6 игроков. Native-ядро упаковано
и развёрнуто на staging (commit `cc31a28`); все пять моделей и завершённое
решение проверены по HTTPS. Следующий шаг — ограниченный решатель тёрна:
[MULTISTREET_SOLVER.md](MULTISTREET_SOLVER.md).
LLM-объяснение, регистрация и лимиты остаются отдельными задачами.


## Где мы сейчас

| Часть | Состояние | Что получает пользователь |
|---|---|---|
| Игра, комнаты с друзьями, практика | Работают | Игровое приложение |
| Текущий тренер | Работает: эквити, модель диапазонов, эвристики действий и размеров, шаблонные объяснения | Действующие подсказки |
| Собственный решатель ривера на 2–6 мест | Реализован как ограниченный исследовательский прототип | Пока не заменяет подсказки на сайте |
| Проверка решений и ускорение | Есть точный эталон малых моделей, native-обучение, проверки лучшего ответа и диагностика выборки | Основа для ограниченного учебного разбора |
| Широкие диапазоны и все улицы | Не решены | Общий солвер ещё не готов |
| Объяснения через LLM API, регистрация, 3 бесплатных разбора и подписка | Не подключены как этот новый режим | Следующий продуктовый блок после доступного расчётного разбора |

Главная причина задержки: последние исследовательские шаги улучшали способы
проверки выборочной стратегии. Они не были обновлениями игрового тренера.
На малой явно заданной модели можно посчитать качество точно; при расширении
диапазонов выборочная оценка пока либо ошибается, либо слишком неопределённа.
Нет оснований считать оставшуюся работу последними несколькими процентами.

Последний исследовательский результат: [структурные пределы](SOLVER_STRUCTURAL_DEVIATION.md)
сузили интервалы фиксированного отклонения, но не сделали автоматический
допуск достаточно чувствительным. Этот путь остаётся исследованием.

## Реализованный локальный этап — учебный разбор ривера

Локальный экран для ограниченной модели реализован с отдельным расчётом после
запроса пользователя. Он доступен независимо от готовности общего солвера.

Границы первой версии:

- Пять фиксированных ситуаций ривера с 1–5 оппонентами и явно заданными небольшими
  диапазонами; можно повторить один и тот же пример.
- Видимые допущения: диапазоны с весами, банк, стеки, доступные размеры ставок
  и предел будущих рейзов. Выбранная модель не выдаётся за всю исходную игру.
- Точный расчёт качества внутри этой модели; частоты действий и значения
  показываются только в том смысле, который действительно посчитан.
- При превышении бюджета, плохом качестве или неподдерживаемом состоянии —
  понятный результат с причиной. Устаревший результат не относится к новой руке.
- Расчёт не блокирует доступные игровые действия. Скрытые карты соперников
  не используются для моделирования того, что герой знал в момент решения.
- Действующий эвристический совет остаётся доступным со своим обозначением
  источника. Учебная модель и обычная подсказка различимы в интерфейсе.

Критерий завершения: пользователь может открыть воспроизводимый пример,
получить ограниченный расчёт и понять его допущения/отказ без просмотра логов.
Сквозные проверки охватывают 2–6 мест, несовместимые карты, ограничения
ресурсов и устаревание результата. Затем отдельно проверяется размещение:
образ включает research/native, проверку ядра и реальные изолированные
расчёты при сборке. Выкладка на Render и HTTP-проверка выполнены; см.
[SOLVER_STAGING.md](SOLVER_STAGING.md).

Базовая версия реализована и размещена на staging с EV и переносом завершённых
решений ривера. Следующее расширение — переход с тёрна на случайный ривер.

## После первого доступного разбора

1. Начать ограниченный решатель тёрна с публичной chance-картой ривера;
   [покрытие улиц и критерии готовности](MULTISTREET_SOLVER.md). Затем флоп.
2. Подключить объяснение через API поверх структурированных расчётных данных.
   Регистрация и серверный учёт трёх бесплатных разборов обязательны до публичного
   платного режима; подписка и её оплата — отдельная законченная задача.
3. Расширять покрытие улиц, диапазонов и размеров ставок по проверяемым случаям.
   Исследования выборки, группировки и многопользовательской стратегии идут
   отдельно от готовности ограниченного учебного интерфейса.

Срок готовности общего солвера сейчас не установлен. Поставки оцениваются
по конкретным возможностям и условиям готовности, а не по числу экспериментов.

Упаковка и включение на staging: [SOLVER_STAGING.md](SOLVER_STAGING.md).
