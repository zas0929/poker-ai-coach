# Poker AI Coach Frontend

Next.js frontend for testing the Texas Hold'em hand flow.

## Run

Start the backend first from `../backend`:

```bash
uvicorn app.main:app --reload
```

Then run the frontend:

```bash
npm install
npm run dev
```

The app uses `NEXT_PUBLIC_API_BASE_URL=http://localhost:8000` by default.

### Языки интерфейса

Переключатель вверху страницы поддерживает английский, русский и украинский языки. Выбор сохраняется в этом браузере и синхронизируется между вкладками. Смена языка не перезапускает раздачу и не переподключает комнату.

Переводы находятся в `i18n/messages.json`. API, действия и сохранённые записи используют прежние идентификаторы; старые англоязычные советы переводятся при отображении. Новые шаблоны текстов сервера следует добавлять в каталог переводов. Проверка каталога и динамических пояснений: `npm run test:i18n`.

### PWA и установка

Приложение можно установить через меню браузера. На iPhone/iPad откройте сайт в Safari и выберите «Поделиться» → «На экран “Домой”». На Android и в настольном Chrome/Edge используйте «Установить приложение» в меню браузера. Для установки с хостинга нужен HTTPS; localhost подходит для разработки.

`app/manifest.ts` задаёт название, standalone-режим, иконки и ярлыки друзей/практики. SVG-исходники и PNG-иконки находятся в `public/icons`, favicon — в `app/favicon.ico`. Service worker регистрируется только в production-сборке.

Без сети открывается локализованный экран переподключения. Service worker хранит только этот экран и публичные иконки: HTML комнат, API, RSC, WebSocket и действия игроков не кешируются. Установленному приложению нужен интернет для игры. Обновление service worker не вызывает принудительную перезагрузку во время раздачи; новая версия активируется после закрытия старых вкладок. При изменении офлайн-ресурсов нужно обновить версию кеша в `public/sw.js`.

Основа конфигурации: [официальное руководство Next.js по PWA](https://nextjs.org/docs/app/guides/progressive-web-apps).
